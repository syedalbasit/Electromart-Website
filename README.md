# ElectroMart 🛒⚡

An e-commerce website for browsing and purchasing electronic devices, built as a web development project using **Python and Django**.

## Features

* Browse electronic products
* Product categories and details
* User-friendly shopping interface
* Dynamic web pages using Django templates
* Static files for styling and frontend resources

## Technologies

* Python
* Django
* HTML
* CSS
* JavaScript
* PostgreSQL

## Project Structure

```text
Electromart-Website/
├── ElectroMart/
├── store/
├── templates/
├── static/
├── manage.py
└── requirements.txt
```

## How to Run

Clone the repository:

```bash
git clone https://github.com/syedalbasit/Electromart-Website.git
cd Electromart-Website
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the Django server:

```bash
python manage.py runserver
```

Open:

```text
http://127.0.0.1:8000/
```
